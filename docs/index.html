WireView Pro II on the Corsair iCUE Nexus

Live per-wire current, total current and total power from a Thermal Grizzly WireView Pro II on the 640×48 iCUE Nexus. iCUE cannot show third-party sensors or web pages on the Nexus, so a small Python daemon paints the panel directly over USB.

Source and setup: github.com/jlobue10/wireview-nexus

Layouts

How it works

WireView Pro II ──USB──▶ HWiNFO64 (shared memory) ──▶ nexus_wireview.py ──HID frames──▶ iCUE Nexus
  1. HWiNFO64 8.41+ reads the WireView Pro II natively. Enable Shared Memory Support and close the Thermal Grizzly app.
  2. pip install -r requirements.txt (hidapi, Pillow), then python nexus_wireview.py --layout combined.
  3. Give the Nexus an empty screen in iCUE so iCUE stops redrawing over the daemon's frames.
